Yama Ahmadi Pro Theme v1.0.0

Install: Appearance > Themes > Add New > Upload Theme. Activate, then visit Settings > Permalinks and click Save Changes once for the PWA routes.

The theme preserves WordPress posts/pages and automatically creates missing core pages. Existing Blocksy-specific header/footer settings are not migrated because they belong to Blocksy.

Languages: built-in FR/EN/DE theme interface. Existing editor-authored page/post text is preserved; use Polylang/WPML if you want separate translated versions of all editorial content.

Location: browser region is used only for a sensible display default; precise geolocation is requested only when the visitor clicks Detect my location.

PWA: installable website app. Android/iPhone install buttons do not claim native App Store/Google Play publication.

After activation, set logo/menu and business details in Appearance > Customize.


v1.1.0: fixed desktop header visibility/spacing, hero alignment, typography, section rhythm, footer logo sizing/overlap, PWA footer responsiveness and mobile layout.

v1.2.0: forced visible dark header on every page, replaced blue Customizer logo in theme chrome with a crisp white Yama Ahmadi brand, and hardened footer/logo sizing against overlap.
